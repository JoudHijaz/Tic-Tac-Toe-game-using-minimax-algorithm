# Tic-Tac-Toe Game – Minimax Algorithm

🔗 **Live Demo:** [Click here to play](https://joudhijaz.github.io/Tic-Tac-Toe-game-using-minimax-algorithm/)

## 🎮 Overview
This project is a fully playable Tic-Tac-Toe game built using **HTML**, **CSS**, and **JavaScript**, where the computer opponent uses the **Minimax algorithm** to make optimal moves. It provides an unbeatable AI for single-player gameplay.

## 🧠 Features
- One-player mode: play against the AI
- AI uses the **Minimax algorithm** to ensure perfect play
- Simple and responsive UI
- Game status messages (win/lose/draw)
- Restart game functionality

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- Minimax algorithm for decision making
